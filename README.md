# Hyejin Jeon

디자이너 전혜진의 홈페이지. 한국어, 영어, 스페인어 및 TEALAY 프로젝트를 포함합니다.

- 웹사이트 원본: `site/`
- 자동 배포: `.github/workflows/pages.yml`
- 이미지·영상 출처: `ASSET_CREDITS.txt`
- GitHub 저장소 이름: `hyejin-jeon`

저장소의 Settings → Pages에서 Source를 GitHub Actions로 설정합니다. main에 업로드하면 실제 Pages 주소를 사용해 썸네일·canonical·사이트맵 주소를 생성하고 공개 배포합니다.

GitHub Pages 주소 앞부분은 로그인한 계정 이름으로 결정되며, 저장소 이름인 hyejin-jeon이 경로에 붙습니다. 이 소스에는 계정 이름이나 임의의 공개 도메인을 확정해 넣지 않았습니다.
